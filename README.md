# Haircube Salon — proposed website

A bilingual (Arabic-first, English) phone-first site for **Haircube Salon**, Al Naeem, Jeddah,
with online booking built in through **Mamar Booking** (choose a barber or “no preference”, a service, a free time).

- Prices on the page come live from the booking system.
- Facts from the salon’s own site and Google listing; reviews are five-star Google reviews quoted as written.
- A proposal prepared by [Mamar](https://mamar.site). Not the salon’s official site.

Live preview: https://ahmedps520-svg.github.io/haircube/
